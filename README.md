
# Sistema de Gestión de Solicitudes Académicas

Trabajo Práctico Integrador de Metodología de Sistemas II.

## Descripción

Sistema desarrollado en Java que permite gestionar solicitudes académicas realizadas por estudiantes.

El proyecto tiene como objetivo analizar la calidad interna y externa del software, identificar problemas de diseño y aplicar mejoras mediante SOLID, Clean Code y refactoring.

Se trabaja con una versión inicial y una versión refactorizada para comparar los cambios realizados.

## Funcionalidades

- Registrar solicitudes académicas.
- Cambiar el estado de una solicitud.
- Asignar responsables.
- Buscar solicitudes por tipo.
- Generar un reporte general.

## Tecnologías

- Java 21.
- Maven.
- Almacenamiento en memoria mediante ArrayList.

## Ejecución

1. Clonar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Configurar JDK 21.
4. Cargar el proyecto Maven.
5. Ejecutar la clase Main.java.

No requiere una base de datos ni configuraciones adicionales.

## Organización

- src/main/java: código fuente del sistema.

## Versiones

El repositorio registra la evolución del sistema mediante commits y tags.

- estado-inicial: versión original del sistema.
- estadorefactorizado: versión final mejorada.
